# 🤝 Contribuindo

Este repositório documenta uma arquitetura e um case study de modernização.

Sugestões devem preservar:

- clareza técnica;
- segurança;
- anonimização;
- documentação reproduzível;
- separação entre conceito e configuração específica de ambiente.

Pull requests devem explicar:

1. O problema.
2. A mudança.
3. O impacto.
4. Como validar.
