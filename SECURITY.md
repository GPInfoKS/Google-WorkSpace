# 🔐 Security

Este projeto é uma documentação de arquitetura e case study sanitizado.

## Nunca publicar

- Senhas
- Tokens
- Chaves privadas
- IPs internos
- Dados pessoais
- Dados de clientes
- Identificadores de infraestrutura
- Configurações administrativas sensíveis
- Exportações do Admin Console contendo dados reais

## Divulgação responsável

Se este repositório for utilizado para documentar uma implementação real, substituir todos os identificadores por exemplos fictícios antes da publicação.
