# 🔎 02 — Levantamento do ambiente

## Objetivo

Conhecer o ambiente atual antes de modificar sua arquitetura.

> **Regra:** primeiro entender, depois alterar.

## Inventário

### 👤 Identidade

- Usuários ativos
- Usuários inativos
- Contas genéricas
- Administradores
- Aliases
- Delegações
- Recuperação de conta

### 📧 E-mail

- Encaminhamentos
- Cópias automáticas
- Filtros
- Catch-all
- Endereços históricos
- Integrações externas
- Sistemas que enviam ou recebem mensagens

### 📁 Arquivos

- Compartilhamentos
- Estrutura de diretórios
- Volume
- Quantidade de arquivos
- Permissões
- Proprietários/responsáveis
- Dados sensíveis
- Duplicidades
- Arquivos obsoletos

### 🖥️ Infraestrutura

- Active Directory
- Servidores
- VPN
- SMB
- Impressoras/scanners
- Sistemas legados
- Dependências de rede
