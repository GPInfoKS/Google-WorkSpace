# 🧪 11 — Piloto e validação

## 🧪 PRIMEIRO A GENTE TESTA

A implantação deve começar com um grupo controlado de usuários, preferencialmente a própria TI.

## 🎯 Objetivos do piloto

- Validar identidade.
- Validar UOs.
- Validar grupos.
- Validar permissões.
- Validar Gmail.
- Validar roteamento.
- Validar Shared Drives.
- Validar Drive para computador.
- Validar políticas.
- Identificar problemas antes da expansão.

## 🔄 Fluxo

```text
🧪 Piloto
   ↓
🔎 Observação
   ↓
🐞 Correções
   ↓
🔁 Novo teste
   ↓
✅ Homologação
   ↓
🚀 Expansão
```

## Critérios de aceite

| Área | Critério |
|---|---|
| Login | Usuário autentica |
| E-mail | Recebe e envia |
| Grupos | Associação correta |
| Drive | Acesso correto |
| Políticas | Aplicação correta |
| Dispositivo | Configuração funcional |
| Segurança | Restrições funcionando |
| Migração | Dados íntegros |
