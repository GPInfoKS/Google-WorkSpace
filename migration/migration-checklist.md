# 🚚 Checklist de migração

## Antes

- [ ] Inventário concluído
- [ ] Responsável definido
- [ ] Permissões levantadas
- [ ] Dados sensíveis identificados
- [ ] Duplicidades avaliadas
- [ ] Destino definido
- [ ] Backup validado
- [ ] Rollback definido

## Piloto

- [ ] Amostra selecionada
- [ ] Migração executada
- [ ] Integridade validada
- [ ] Permissões validadas
- [ ] Usuários testaram
- [ ] Problemas registrados

## Lote

- [ ] Janela definida
- [ ] Comunicação enviada
- [ ] Migração executada
- [ ] Relatório gerado
- [ ] Homologação realizada

## Encerramento

- [ ] Período de segurança concluído
- [ ] Aceite do departamento
- [ ] Backup/retensão definidos
- [ ] Legado documentado
- [ ] Desativação autorizada
