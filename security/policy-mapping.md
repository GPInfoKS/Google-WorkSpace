# 🛡️ Mapeamento de políticas

| Política legada | Objetivo | Mecanismo alvo | Status |
|---|---|---|---|
| GPO navegador | Padronização | Chrome Management | 🔎 Avaliar |
| Política senha | Autenticação | Workspace | 🔎 Avaliar |
| Mapeamento SMB | Arquivos | Shared Drives | 🔄 Substituir |
| Restrição USB | Segurança | Endpoint | 🔎 Avaliar |
| GPO configurações | Padronização | Workspace/Chrome/Endpoint | 🔧 Adaptar |
| NTFS | Permissões | Groups + Shared Drives | 🔄 Substituir |

## Método

> Mapear **objetivo → controle equivalente**, não simplesmente **GPO → configuração**.
